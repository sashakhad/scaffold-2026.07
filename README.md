# Project Compass

A shared, short view of Sasha’s active projects for Melissa. Twenty-one projects, with the guardrail, the financial and play notes, and a page for each project. Notes stay in the browser. There is no login.

## Run it

- Node.js 24 (see `.nvmrc`)
- pnpm 11 via Corepack

```bash
corepack enable
pnpm install
pnpm dev
```

Open http://localhost:3000.

Postgres is unused by this site. The scaffold’s Prisma setup is still here if a later version needs it.
