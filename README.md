# Project Compass

A phone-readable overview of Sasha’s projects for Melissa. No password gate. The album (High Tide — Bula!) is rank 1. PIGU and Gaochao share rank 2. The legal name is Gaochao LLC.

This app was created from the project scaffold (Next.js App Router, React, TypeScript, Tailwind CSS, and shadcn/ui). Postgres is optional and unused by this page.

## Commands

| Command  | What it does                                   |
| -------- | ---------------------------------------------- |
| `/setup` | Installs dependencies and creates `.env`       |
| `/start` | Launches the app at http://localhost:3000      |
| `/help`  | Lists the commands that belong to this project |

## First time

Requirements: Node.js 24 LTS and pnpm 11 via Corepack.

```bash
corepack enable
corepack prepare pnpm@11.13.1 --activate
pnpm install
pnpm run dev
```

Open http://localhost:3000.
